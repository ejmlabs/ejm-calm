# Changelog

calm follows [Semantic Versioning](https://semver.org/). The site deploys from main; versions mark notable states of it.

## [Unreleased]

- Joins the shared ejmlabs gate and continuous deploys: each merge to main deploys to staging.calm.ejmlabs.com, then to calm.ejmlabs.com.

## [0.1.0] - 2026-10-31

- A procedural ocean from one seed: a blue whale migrating between continents, ships, birds, weather and a day cycle.
- A cinematic frame: HDR output with antialiasing, bloom past white and a grade, one tone curve for every material, sunsets, storm foam and finer land.
- Strict TypeScript, the shared strict lint layer and Prettier, with a local gate of lint, unit tests and a browser smoke.
